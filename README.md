# Google learning | Skunkworks Academy

This repository hosts the Google learning hub at `https://google.skunkworksacademy.com/` using GitHub Pages. Its content points to official Google learning resources; programme and exam availability, pricing and eligibility should be checked with their providers.

The Academy's shared navigation, footer, theme and contrast runtime load from the main site. The page includes fallback navigation if those assets are unavailable. `index.html` and `learning.css` are also maintained at `skunkworks-academy/www` under `google/` for the Academy's existing `/google/` route. Keep both copies in sync when content or styles change; the Academy route retains its existing publisher-policy `noindex` setting, while the subdomain uses its own canonical URL.

The browser workflow checks the rendered page in light and dark themes at mobile, tablet and desktop widths. It also checks the shared shell, mobile navigation, section anchors, horizontal overflow and WCAG accessibility rules, and uploads screenshots for review.

Primary sources: [Google for Education Learning Center](https://edu.google.com/intl/ALL_in/learning-center/), [Google educator certifications](https://edu.google.com/intl/ALL_in/learning-center/certifications/), [Google Cloud certifications](https://cloud.google.com/learn/certification), [Google Career Certificates in Africa](https://grow.google/intl/ssa-en/google-career-certificates/) and [Google Skills](https://www.skills.google/).
